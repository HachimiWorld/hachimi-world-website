Install on iPhone

The iOS package (IPA) is unsigned, so you need to sign it with your own Apple ID before it can be installed. The steps below use Sideloadly; the first install takes about ten minutes.

Download IPA Open the web app

The web app needs no installation and runs in Safari on iPhone.

01

What you need

  • A Windows PC or a Mac, and a cable to connect your iPhone.
  • An Apple ID. A free one works. If you have concerns, use a separate account.
  • The Hachimi World IPA, from the button above.
02

Install with Sideloadly

  1. Install Sideloadly

    Download and install it from sideloadly.io. On Windows, also install iTunes and iCloud from Apple's website; the Microsoft Store versions do not work.

  2. Connect your iPhone

    Connect it to the computer with the cable, unlock it, and tap “Trust” when asked.

  3. Sign and install

    Drag the IPA into the Sideloadly window, enter your Apple ID, click Start, then enter your password and two-factor code when prompted. When it finishes, the app appears on your Home Screen.

  4. Trust the developer

    On your iPhone, open Settings → General → VPN & Device Management, select your Apple ID and tap “Trust”.

  5. Turn on Developer Mode

    Required on iOS 16 and later. Open Settings → Privacy & Security → Developer Mode, turn it on, restart when prompted, then confirm once more.

03

Expiry and updates

  • Apps signed with a free Apple ID expire after 7 days and then won't open. Repeat step 3 with the same Apple ID.
  • A free Apple ID can keep at most 3 self-signed apps at a time.
  • Apps signed with a paid developer account last 1 year.
  • When a new version is released, download the new IPA and install it the same way, from step 3.
04

Other signing tools

AltStore and SideStore can also install IPAs, and can re-sign apps on the phone so you don't need to connect to a computer each time. See their websites for setup, then import the Hachimi World IPA.

05

Common problems

“Untrusted Developer” when opening the app
Complete step 4.
Developer Mode is missing from Settings
It only appears after the first self-signed app is installed. Complete step 3, then look again.
The app worked before but won't open now
The signature has expired. Repeat step 3.
Something else
Ask on Discord or in GitHub Discussions.
