在 iPhone 上安装

iOS 安装包（IPA）未经签名，需要用自己的 Apple ID 签名后才能安装。以下以 Sideloadly 为例，第一次安装约需十分钟。

下载 IPA 打开网页版

网页版无需安装，可在 iPhone 的 Safari 中直接使用。

01

准备

  • 一台 Windows 或 Mac 电脑，以及连接 iPhone 的数据线。
  • 一个 Apple ID，免费账号即可。如有顾虑，可使用单独注册的账号。
  • 基米天堂 IPA 安装包，可从本页上方下载。
02

使用 Sideloadly 安装

  1. 安装 Sideloadly

    从 sideloadly.io 下载并安装。Windows 还需要安装 Apple 官网提供的 iTunes 与 iCloud，Microsoft Store 中的版本不可用。

  2. 连接 iPhone

    用数据线连接电脑并解锁 iPhone，在弹出的提示中选择“信任”。

  3. 签名并安装

    将 IPA 拖入 Sideloadly 窗口，在 Apple ID 一栏填写账号，点击 Start，按提示输入密码与双重认证验证码。完成后，应用会出现在主屏幕上。

  4. 信任开发者

    在 iPhone 上打开“设置 → 通用 → VPN 与设备管理”，选择自己的 Apple ID，点击“信任”。

  5. 开启开发者模式

    iOS 16 及以上需要此步骤。打开“设置 → 隐私与安全性 → 开发者模式”，开启后按提示重启，重启后再确认一次。

03

有效期与更新

  • 免费 Apple ID 签名的应用有效期为 7 天，到期后无法打开。用同一 Apple ID 重新执行第 3 步即可。
  • 免费 Apple ID 同一时间最多保留 3 个自签名应用。
  • 付费开发者账号签名的应用有效期为 1 年。
  • 新版本发布后，下载新的 IPA，同样按第 3 步安装。
04

其他签名工具

AltStore 与 SideStore 同样可以安装 IPA，并能在手机上续签，省去每次连接电脑。安装方式见各自官网，装好后导入基米天堂的 IPA 即可。

05

常见问题

打开时提示“不受信任的开发者”
完成第 4 步。
设置中找不到“开发者模式”
该选项在安装第一个自签名应用后才会出现。先完成第 3 步，再回到设置中查找。
应用此前正常，现在无法打开
签名已过期。重新执行第 3 步即可。
